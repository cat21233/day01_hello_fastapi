# t-170 CoT 对比实验存档（2026-09-09）

## 实验设置（单变量对照）

| 控制项 | 值 |
|---|---|
| 模型 | `deepseek-chat`（A/B 同一模型，结论才有效） |
| temperature | 0（锁确定性，排除随机性） |
| 题目 | 一个三位数，各位数字之和 15，个位比十位大 3，百位是十位的 2 倍，求这个三位数 |
| 唯一变量 | user 消息末尾是否加「请一步一步推理，最后再给出答案」 |

**正确答案：636**（十位 b=3 → 百位 2b=6，个位 b+3=6；验证 6+3+6=15 ✓、6-3=3 ✓、6=2×3 ✓）

## 结果对比

| 版本 | Prompt | 输出 | 答案对错 | 推理过程 |
|---|---|---|---|---|
| A 直接答 | 「直接给出答案，不要解释。」 | `483` | ✗ 错（4+8+3=15 虽对，但个位3<十位8，违反约束） | 无 |
| B CoT | 「请一步一步推理，最后再给出答案。」 | 设 a/b/c 列方程组 → 代入化简 → 4b=12 → b=3 → a=6, c=6 → 逐步验证 → **636** | ✓ 对 | 有，五步+验证 |

## 预备实验（鸡兔同笼，agnes-2.0-flash）

- A 直接答：鸡 23 只、兔 12 只 → ✓ 对
- 结论：题目太简单时 CoT 无增量优势；**难题（多约束）才能拉开差距**——所以正式实验换了三位数题

## 结论

1. **CoT 把「心算」变「笔算」**：无 CoT 时模型一步到位猜答案（483 错）；有 CoT 时分解为多步，每步出错率独立且低，最后还有验证环节兜底
2. CoT 的代价：输出更长（token 更多、更慢更贵）——简单任务不必上 CoT，**难推理任务才值得**
3. 实验方法论：单变量对照（同一模型 + temperature=0，一次只动一个旋钮）；中途换模型=引入混杂变量，实验作废重跑
