## 二、概念预习（理解"为什么"，明天才写得出来）

### 概念 1：为什么你的接口现在是"裸奔"的

你 D3 写的 `get_token`/`get_current_user` 子依赖是**假的**——token 是硬编码的字符串，谁都能猜到。真实世界的认证要回答两个问题：

- **你是谁？**（authentication，认证）→ 出示凭证（用户名密码 / token）
- **你能干什么？**（authorization，鉴权）→ 检查你的权限

明天的目标：让 `/users/me` 这类接口**真的要求用户登录才能访问**，没带有效 token 就返回 401。

### 概念 2：JWT 三段式结构（核心中的核心）

JWT（JSON Web Token）是一串**自包含**的字符串，长这样：

```
eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIxIiwibmFtZSI6InpoYXVoIn0.s0m3s1gn4tUr3
```

用 `.` 拆成三段：

| 段 | 内容 | 作用 |
|----|------|------|
| **header** | 算法 + 类型（`{"alg":"HS256","typ":"JWT"}`） | 告诉服务端用什么算法验签 |
| **payload** | 声明（claims）：`sub`(用户id)、`exp`(过期时间)、`name` | 业务数据，**明文可读** |
| **signature** | 用密钥对前两段做签名 | **防篡改**——改一个字符，验签就失败 |

**关键认知**：
1. payload 是 base64 编码，**不是加密**——任何人能解码看到内容，所以**别放密码**！
2. 安全性靠 signature：服务端用**只有自己知道的密钥（secret）**验签，签名对不上 = token 被改过 = 拒绝
3. 自包含 = 服务端**不用存 session**，验签通过就信它——这就是 JWT 比传统 session 适合 API 的原因

### 概念 3：登录 → 签发 → 访问 全流程（明天的主线）

```
1. 客户端 POST /token  (username, password)
2. 服务端查用户 → 用 bcrypt 验证密码哈希
3. 密码对 → 服务端用 secret 签发 JWT（含 sub=用户id, exp=过期）
4. 返回 {"access_token": "<jwt>", "token_type": "bearer"}
5. 客户端后续请求带请求头: Authorization: Bearer <jwt>
6. 服务端 get_current_user 依赖: 解析 header → 验签 → 取 sub → 返回用户
7. token 无效/过期 → 401 Unauthorized
```

你在 D3 学的"子依赖"（`get_token` → `get_current_user`）明天会**原样复用**，只是把"查硬编码 token"换成"验签 JWT"。

### 概念 4：密码为什么必须哈希（bcrypt）

**绝不能用明文存密码**——数据库泄露=所有用户密码泄露。正确做法：

- 存的是密码的**哈希值**（单向函数，算出来回不去）
- bcrypt 是带盐（salt）的哈希，**同一个密码每次哈希结果都不同**，防彩虹表
- 验证时：`bcrypt.check(password, 库里存的哈希)` → True/False，**不比较明文**

### 概念 5：三个新库，各管一件事

| 库 | 管什么 |
|----|--------|
| `python-jose` | 签发 JWT（encode）和验证（decode） |
| `passlib` + `bcrypt` | 密码哈希（hash）和验证（verify） |
| `python-dotenv`（已有） | 存 secret 密钥到 .env（别写死在代码里！） |

## 四、环境坑提醒（提前踩，明天少痛）

- **装库**：`uv pip install python-jose[cryptography] "bcrypt==4.0.1" "passlib==1.7.4"`（uv 的 venv 没 pip，用 uv pip）
- ⚠️ **passlib + bcrypt 版本坑**：passlib 1.7.4 和 bcrypt ≥4.1 会报 `AttributeError: module 'bcrypt' has no attribute '__about__'`——**必须锁 `bcrypt==4.0.1`**，这是全网高频坑
- ⚠️ **python-jose 的包名**：import 是 `from jose import jwt`（不是 `from python_jose`）
- **secret 放 .env**：`SECRET_KEY=...`，别写死在代码里；密钥自己编一串随机字符串
- **别把密码放 JWT payload**（明文可读，前面讲过）
- 沙箱老规矩：`--reload` 不生效，改代码手动重启；push 需 VPN
